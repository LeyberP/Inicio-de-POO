# Inicio de POO

**T2.2 Fase 1 APE4 – Inicio de Programación Orientada a Objetos (Java)**

Repositorio con cinco ejercicios introductorios de POO en Java: definición de clases, atributos, constructores, métodos, creación de objetos (instancias), arreglos de objetos y referencias.

## 📂 Descripción de las carpetas

| Carpeta | Contenido |
|---|---|
| [`Codigos/`](Codigos) | Contiene los 5 ejercicios. Cada ejercicio tiene su propia subcarpeta con el código fuente (`.java`), una carpeta `Captura/` con la salida del programa y un `readme.md` con su explicación. |
| [`Codigos/Notas del curso/`](Codigos/Notas%20del%20curso) | **Ejercicio 1.** Clase `Estudiante`: calcula el promedio de 3 notas y clasifica a cada estudiante como Aprobado, Supletorio o Reprobado. |
| [`Codigos/Inventario de una tienda/`](Codigos/Inventario%20de%20una%20tienda) | **Ejercicio 2.** Clase `Producto`: muestra precios, simula ventas, avisa cuándo reponer y calcula el valor total del inventario. |
| [`Codigos/Veterinaria/`](Codigos/Veterinaria) | **Ejercicio 3.** Clase `Mascota`: muestra mascotas, avisa si el peso supera 20 kg y demuestra que asignar objetos copia la *referencia*, no el objeto. |
| [`Codigos/Cuenta de ahorro/`](Codigos/Cuenta%20de%20ahorro) | **Ejercicio 4.** Clase `Cuenta`: usa un `while` para depositar 50 por mes hasta llegar a 500 y cuenta los meses necesarios. |
| [`Codigos/Biblioteca/`](Codigos/Biblioteca) | **Ejercicio 5.** Clases `Libro` y `Socio`: registra préstamos de libros y muestra el estado de cada libro y socio. |
| [`Doc/`](Doc) | Documento PDF con el enunciado de la actividad. |

## ▶️ Cómo ejecutar cualquier ejercicio

1. Clona el repositorio:
   ```bash
   git clone https://github.com/LeyberP/Inicio-de-POO.git
   cd Inicio-de-POO/Codigos
   ```
2. Entra a la carpeta del ejercicio, compila **todos** los `.java` de esa carpeta y ejecuta la clase `Main` correspondiente:

   | Ejercicio | Comandos |
   |---|---|
   | 1. Notas del curso | `cd "Notas del curso"` → `javac *.java` → `java Main` |
   | 2. Inventario de una tienda | `cd "Inventario de una tienda"` → `javac *.java` → `java Main2` |
   | 3. Veterinaria | `cd Veterinaria` → `javac *.java` → `java Main3` |
   | 4. Cuenta de ahorro | `cd "Cuenta de ahorro"` → `javac *.java` → `java Main4` |
   | 5. Biblioteca | `cd Biblioteca` → `javac *.java` → `java Main5` |

> Las carpetas con espacios en el nombre deben ir entre comillas en la terminal. El detalle de cada ejercicio está en su propio `readme.md`.

## 🧰 Requisitos

- **JDK 8 o superior** (se probó con un JDK moderno). Verifica con `java -version` y `javac -version`.
- Una terminal, o un IDE como IntelliJ IDEA, NetBeans, Eclipse o VS Code con el *Extension Pack for Java*.
